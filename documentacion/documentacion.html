Cómo usar Hogar Amigo Peludo

Un recorrido por las acciones principales de la plataforma.

01
Imagen: explorar mascotas

Explora

Visita el catálogo y conoce las mascotas disponibles.

02
Imagen: solicitud de adopción

Solicita

Elige una mascota y completa el formulario de adopción.

03
Imagen: registro de usuario

Regístrate

Crea una cuenta o inicia sesión para enviar y consultar la solicitud.

04
Imagen: seguimiento del adoptante

Haz seguimiento (adoptante)

Consulta el estado de tu solicitud y los datos del proceso de entrega.

05
Imagen: panel administrativo

Seguimiento (administrador)

Revisa solicitudes, actualiza estados y coordina las entregas.

🐾
Perfil

Adoptante

  1. Buscar mascotas: usa el catálogo para revisar sus datos.
  2. Enviar solicitud: abre la mascota elegida y completa el formulario.
  3. Consultar perfil: revisa tus datos y solicitudes activas.
  4. Ver entrega: consulta fecha, dirección y estado del proceso.
⚙️
Perfil

Administrador

  1. Gestionar mascotas: crea, actualiza y cambia su disponibilidad.
  2. Revisar solicitudes: acepta, rechaza o actualiza cada proceso.
  3. Coordinar entregas: registra transportista, fecha y novedades.
  4. Supervisar datos: consulta la información desde el panel.
💡

Consejo: ejecuta el frontend con Live Server y el backend Spring Boot en localhost:8080 para probar todas las funciones localmente.
