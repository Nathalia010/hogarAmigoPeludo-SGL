# 🐾 Hogar Amigo Peludo

> **Plataforma web para la gestión y adopción responsable de mascotas**

## 📌 Descripción del proyecto

**Hogar Amigo Peludo** es una plataforma web desarrollada con el propósito de facilitar y organizar los procesos relacionados con la **adopción responsable de mascotas**, permitiendo centralizar la información de animales, usuarios y solicitudes de adopción.

El proyecto nace como respuesta a la problemática que enfrentan algunas fundaciones y refugios de animales al gestionar sus procesos mediante hojas de cálculo, llamadas telefónicas y diferentes canales de comunicación. Esta situación puede generar pérdida de información, retrasos y dificultades para realizar seguimiento a las solicitudes y procesos de adopción.

Nuestra solución busca proporcionar una herramienta digital que permita mejorar la organización de la información y facilitar la conexión entre **fundaciones, adoptantes y personas interesadas en el bienestar animal**.

---
## 🎯 Objetivo general

Desarrollar una plataforma web que facilite la gestión de los procesos de adopción responsable de mascotas, centralizando la información de animales, usuarios y solicitudes para mejorar la organización, seguimiento y eficiencia de los procesos de una fundación animal.

## 🎯 Objetivos específicos

* Diseñar una interfaz web intuitiva y accesible.
* Centralizar la información de las mascotas disponibles para adopción.
* Implementar una base de datos relacional para almacenar la información del sistema.
* Desarrollar un backend que permita gestionar los datos de la plataforma.
* Establecer procesos para el registro y seguimiento de solicitudes de adopción.
* Facilitar la administración de la información por parte de la fundación.
* Aplicar buenas prácticas de desarrollo de software y control de versiones.

---

## ✨ Funcionalidades principales

### 🐶 Gestión de mascotas

Permite administrar la información relacionada con las mascotas disponibles, facilitando su consulta y organización.

### 👤 Gestión de usuarios

Permite estructurar y administrar la información de los usuarios que participan en los procesos de la plataforma.

### ❤️ Solicitudes de adopción

Los usuarios interesados pueden iniciar un proceso de adopción y proporcionar la información necesaria para su evaluación.

### 📋 Administración de solicitudes

La fundación puede consultar y gestionar las solicitudes recibidas, permitiendo realizar seguimiento al estado de cada proceso.

### 🚚 Gestión de entregas

Se establece una estructura para realizar seguimiento a la entrega de las mascotas una vez finalizado el proceso de adopción.

### 🗄️ Base de datos

La información del sistema se almacena de manera estructurada mediante una base de datos relacional.

### 🔌 API REST

El backend proporciona una API REST para gestionar la comunicación entre la interfaz de usuario y la base de datos.
